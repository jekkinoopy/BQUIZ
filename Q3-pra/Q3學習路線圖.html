A

先搞懂現況：這是兩份不同的題目

資料夾裡現成的 front / back / api / css / js / 102202，是老師已經完整做出來的 17300-102202「健康促進網社群平台」參考解答——從 git 紀錄可以看到它是一步步蓋起來的：註冊、登入、 忘記密碼、瀏覽人次、後台選單、帳號與文章管理、分類網誌頁籤、人氣文章按讚，最後是問卷投票。

你現在要準備的，是試題本第 56–70 頁的 17300-102203「ABC 影城」——四份官方題目（102201～102204）裡的 第三題，跟 102202 是「同一套出題格式、不同情境」的姊妹題：一樣要建網站資料夾、一樣有標題區／主選單／動態廣告／ 頁尾／後台管理，只是把「文章與問卷」換成了「電影、預告片與訂票」。

學習策略：不要把 102202 從頭讀到尾。把它當「工法字典」——規格書裡重複出現的部分，直接照抄老師的寫法； 真正該花時間的，是 102203 才有、102202 裡完全找不到對應寫法的新功能。
B

學習進度總覽

PHASE 0約 0.5 天

環境暖身：先讓老師的專案跑起來

用 XAMPP 把 db19.sql 匯入、跑起 102202 前台後台， 自己登入一次、投一次票、看一次後台管理。目的不是複習 102202 的功能，而是確認你有能力「讀」接下來的程式碼—— 看得懂資料庫欄位對應到哪支 API、哪支 API 又被哪個頁面呼叫。

PHASE 1約 1 天

對照下面的「程式碼地圖」，讀懂老師的共用工法

照著 C 節的表格，一行一行對照「規格概念 → 檔案」，弄懂：登入驗證怎麼寫、 後台選單框架怎麼搭、分頁邏輯怎麼算、AJAX 怎麼跟 API 溝通。這些工法在 102203 幾乎原封不動可以用。

PHASE 2約 0.5 天

快速核對 102203 裡「重複」的段落

只需對照動作要求 (一)(二)(三)(十)——建資料夾、版面尺寸、伺服器、主選單、資料備份， 確認寫法跟 102202 一致即可，不用重新學，直接複製既有寫法改名字。

PHASE 3約 3–4 天

攻克 102203 專屬功能（重點都在這裡）

建議順序：① 先設計資料庫（電影／場次／座位／訂單）② 預告片海報輪播 ③ 院線片清單＋簡介頁 ④ 線上訂票完整流程（最複雜，留最多天數） ⑤ 後台五大管理模組。 每完成一塊，回頭對照評審表的扣分項目自我檢查一次。

PHASE 41 天起

整合＋限時模擬考

用題本規定的 240 分鐘跑一次完整流程，包含備份步驟；結束後拿評審表逐項打勾， 找出還缺哪個「＊」或「★」小項。

D

102203 試題本逐段大綱（從頭到尾）

依題本原本的順序列出，頁碼是題本自己印的頁碼；照這個順序讀，不用跳著找。

  1. 所需檔案清單p.54🔵

    預告片、電影海報、分級圖示、訂票座位圖、院線片影片檔、3 種版型檔、共用函式庫。掃過去記住檔名代碼（03A/03B/03C/03D）就好。

  2. 試題說明一～七p.54–55⚪

    資料夾結構、軟體安裝規定、須自行完成項目、評分方式、錯字扣分、評分標準——四份題本一字不差，讀懂一次就不用每題重讀。

  3. 動作要求 (一) 建資料夾、版面尺寸、伺服器p.55⚪

    webXX／dbXX 命名、1024×768、上下左右留 10px、本機 Web／DB 伺服器要能跑——跟 102202 完全一樣的四小項。

  4. 動作要求 (二) 網站架構與版型p.55–58 · 圖1–7🟠

    架構圖＋首頁版型（標題／主選單／動態廣告／預告片導覽區／院線片清單區／頁尾）沿用舊概念；但多了一種全新的 「院線片簡介」版型，後台管理選單也要記熟 5 個項目名稱（網站標題／動態文字／預告片海報／院線片／電影訂票管理）。

  5. 動作要求 (三) 主選單區p.58–59 · 圖8⚪

    首頁／線上訂票／會員系統／管理系統四個連結，管理系統預設帳密 admin / 1234——跟 102202 進後台的判斷邏輯一樣。

  6. 動作要求 (四) 預告片海報導覽區p.60–61 · 圖9–10🟠 重點

    動畫輪播、按鈕列最多顯示 4 個、超過用「◀ ▶」捲動、至少 6 張海報、切換要有轉場效果（淡入／縮放／滑出擇一實作）。 102202 完全沒有對應功能，是這題最需要額外練的前端動畫。

  7. 動作要求 (五) 後台預告片海報管理p.61 · 圖11🟠

    新增／刪除／設定是否播放／設定播放順序／設定轉場效果——CRUD 部分可參考後台文章管理的寫法，但多了「排序」跟「效果設定」兩個新欄位。

  8. 動作要求 (六) 院線片清單區p.62–63 · 圖12–14🟠 重點

    上映檔期＝上映日起 3 天、2×2 排版一頁 4 部、超過分頁、自動過濾已下檔電影、點「線上訂票」要帶入所選電影、 點海報／劇情簡介進入院線片簡介頁（含預告片播放）。分頁排版可抄最新文章分頁，但「日期區間自動過濾」是新邏輯，要特別注意。

  9. 動作要求 (七) 後台院線片清單管理p.63–64 · 圖15–16🟠

    新增電影要填片名／分級下拉／片長／上映日期（年月日三欄）／發行商／導演／預告影片／海報／簡介；還要能修改、刪除、上下架、排序。 CRUD 工法重複，但欄位多、有影片＋圖片兩種檔案上傳，要留意表單設計。

  10. 動作要求 (八) 前台線上訂票功能p.64–67 · 圖17–20🟠🟠 全題最重

    電影／日期／場次三層連動下拉、5 個場次時段各自算剩餘座位（20 席扣已訂）、挑選座位 4×5 矩陣（已售／未售圖示、最多勾 4 個）、 訂單編號規則（8 碼日期＋4 碼流水號）、產生訂單頁面。這是全題唯一沒有前例可抄的完整新流程，練習時間要最多留給它。

  11. 動作要求 (九) 後台電影票訂單管理p.67 · 圖21🟠

    訂單列表（編號／片名／日期／場次／數量／位置）、單筆刪除、依電影快速刪除、依日期快速刪除（皆需確認視窗）——列表與刪除工法可參考後台文章管理。

  12. 動作要求 (十) 資料備份p.68⚪

    webXX 主文件目錄、6 支 xampp 環境設定檔、資料庫、PHP／ASP.NET 兩種備份清單——跟其他三份題本一字不差，考前把備份流程背一次，不用每題重讀。
